# Bilancio Website

Sitio web público y comercial de [Bilancio](https://bilancioapp.com), orientado a presentar el producto y sus funcionalidades.

## Tecnología prevista

- Astro, TypeScript y CSS.
- Generación estática y despliegue en Cloudflare Pages.

## Desarrollo

Este repositorio está en etapa inicial. La estructura, los comandos de desarrollo y la documentación se incorporarán a medida que avance el proyecto.

La aplicación se encuentra en [app.bilancioapp.com](https://app.bilancioapp.com); este repositorio contiene únicamente la web pública.
