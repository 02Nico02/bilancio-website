Claridad conceptual

Todos saben cómo están las cuentas.

El sistema distingue de forma transparente tres componentes clave para que nunca existan malentendidos entre los integrantes.

1 Automático

Balance calculado

El resultado neto exacto entre lo que una persona aportó efectivamente y lo que le correspondía pagar por los consumos en los que participó.

Ejemplo
Nicolás (Neto) +ARS 1.300 a favor
2 Algoritmo

Pago sugerido

Recomendación matemática inteligente diseñada para minimizar la cantidad de transferencias requeridas para saldar el grupo por completo.

Optimización
Lucía ➔ Nicolás ARS 800
3 Manual

Pago registrado

Liquidaciones reales anotadas de común acuerdo cuando un integrante transfiere dinero a otro por fuera de la plataforma, actualizando el saldo al instante.

Comprobante
Transferencia acreditada Registrado
