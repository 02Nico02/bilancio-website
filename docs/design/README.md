# Diseño de Bilancio Website

## Dirección aprobada

La dirección artística es **Editorial Product Showcase**: una estética editorial, clara y profesional; fondos cálidos; verde bosque institucional; titulares en Newsreader; interfaz y textos en Plus Jakarta Sans; composición espaciosa y demostraciones del producto como protagonistas.

Se aprobaron referencias Stitch para Home desktop, Home mobile y Gastos grupales desktop. La variante mobile de Gastos grupales queda pendiente para la implementación.

## Cómo usar las referencias

Los mockups de [Stitch](references/stitch/) comunican dirección y composición; no son diseños pixel-perfect ni la implementación definitiva. Codex puede adaptar y perfeccionar la solución manteniendo la dirección aprobada y respetando responsive, accesibilidad y el producto real.

No copies automáticamente HTML, CSS, Tailwind CDN, scripts, imágenes externas ni textos comerciales no verificados. Las referencias no establecen dependencias técnicas. No modifiques arbitrariamente los originales de Stitch.
