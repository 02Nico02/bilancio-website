## Fuentes de verdad

| Fuente | Autoridad |
| --- | --- |
| Código y tests | Comportamiento implementado |

Ante una discrepancia, verifica el comportamiento en el código y los tests. Distingue las decisiones documentadas de las capacidades implementadas.
